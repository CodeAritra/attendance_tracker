# 📝 Attendance Tracker App

A full-stack web application to help students **upload class routines**, **mark daily attendance**, and **track attendance percentage** — all in one clean and user-friendly dashboard. Built using the **MERN stack**.

🔗 **Live Demo**: [Click Here to View the App](https://attendance-tracker-five-rose.vercel.app/)

---

## 🚀 Features

- 📅 **Routine Upload**  
  - Upload your class routine and view it in a structured layout  
  - Automatically organizes by weekdays  

- ✅ **Attendance Management**  
  - Mark subjects as **Present** or **Absent** each day  
  - View a real-time dashboard of attendance per subject  
  - Tracks **attendance percentage** to keep you informed

- 🔐 **Authentication**  
  - Secure login and session management using **JWT**

- ☁️ **Deployment**  
  - Fully deployed using **Render's free hosting service**  
  - Ensures accessibility from any device, anywhere  

---

## 🧰 Technologies Used

- 💻 **Frontend**: React.js, Tailwind CSS  
- 🧠 **Backend**: Node.js, Express.js  
- 🗄️ **Database**: MongoDB  
- 🛠️ **Others**: JWT, Mongoose, Cloud Hosting on Render
